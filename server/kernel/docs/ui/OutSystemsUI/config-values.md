## CarouselItems

Number of visible Carousel items at the same time on each slide.

- Desktop: Integer = 1 - Number of visible Carousel items at the same time on each slide, on Desktop.
- Tablet: Integer = 1 - Number of visible Carousel items at the same time on each slide, on Tablet.
- Phone: Integer = 1 - Number of visible Carousel items at the same time on each slide, on Phone.

## CarouselOptionalConfigs

Group of optional configurations for the Carousel block.

- AutoPlay: Boolean = True - Set if the Carousel sould change slides automatically. 

Default value is true.
- Loop: Boolean = True - Enable continuous slide of the Carousel even after it reaches the end.
- Padding: Text - Distance between the Carousel edges and the visible items on each slide.

Accepts any css size unit (like px, vw, %) or even css variables.

Example: "100px"
- ItemsGap: Text - Distance between each Carousel item.

Accepts any css size unit (like px, vw, %) or even css variables.

Example: "var(--space-base)"
- StartingPosition: Integer - Set the first element to show.

## DropdownOption

Structure used on Dropdown option items.

- Value: Text [obrigatorio] - Set the items's value.
- Label: Text [obrigatorio] - Set the items's text.
- ImageUrlOrIconClass: Text - Pass an image URL or a CssClass, If an URL, an image will be added otherwise the this info will be used as a class selector and an icon will be added.
- GroupName: Text - Set the name of the group where the item belongs. Use this property to divide the dropdown options into groups. The GroupName will appear in the heading of the group.
- Description: Text - Set the text that will be displayed below the option value in the Dropdown options list. 
Use this property to give more details about the option.

## DropdownOptionalConfigs

DropdownSearch optional configurations

- AllowMultipleSelection: Boolean = False - Set to allow the selection of multiple options. By default, False.
- IsDisabled: Boolean - Set as True to disable the Dropdown.
- NoResultsText: Text = "There are no options to show." - Text that will be presented when there are no results to show.
- SearchPrompt: Text = "Search..." - Prompt text that will appear at the search input.
- NoOptionsText: Text = "There are no options to show." - Set the message that is displayed in the Dropdown list when there are no options available. 

By default, “There are no options to show".
- SanitizeDropdownValues: Boolean = False - Set true to assure the values inputted in the dropdown will be sanitized or false if you want to explicitly allow custom code to run.
By setting it to true it will replace HTML tags from option's text (value and label) to prevent potential injected code execution.  
This option is not enabled by default to avoid performance issues.

- Muted: Boolean = False - Set to True to disable the audio of the video. False, otherwise.
By default, the video is not muted (False).
- PosterURL: Text - Set the URL to the poster image that displays before the video starts.
