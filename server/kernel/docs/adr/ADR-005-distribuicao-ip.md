# ADR-005: Distribuicao e IP

Data: 2026-09-04. Estado: aceito (dono + agente).

## Decisao

Nenhum binario da OutSystems no pacote; o produto carrega as DLLs do Studio instalado do cliente. Decompilado e notas de pesquisa fora deste repo. Nucleo (spec, compilador, convencoes, merge, adaptadores) so como binario ofuscado com licenca; CLI/SDK finos; on-prem; telemetria opt-in sem OML nem credencial. Revisao juridica da EULA antes de vender.
